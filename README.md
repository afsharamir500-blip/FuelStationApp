# برنامه جایگاه‌های سوخت (نمونه اولیه)

## نحوه باز کردن پروژه
1. Android Studio را باز کنید → Open → پوشه `FuelStationApp` را انتخاب کنید.
2. صبر کنید Gradle Sync تمام شود (نیاز به اینترنت برای دانلود کتابخانه‌ها دارد).
3. Run را بزنید.

## چه چیزی آماده است
- صفحه اصلی: لیست جایگاه‌ها با شماره جایگاه، نام، آدرس و قیمت هر لیتر (تومان).
- صفحه پرداخت: وارد کردن مقدار لیتر → محاسبه خودکار مبلغ کل.
- صفحه رسید: نمایش رسید پس از پرداخت (کد پیگیری، تاریخ، مبلغ).
- صفحه موجودی کارت سوخت: نمایش موجودی سهمیه.

## چه چیزی باید خودتان اضافه کنید (به دلیل نیاز به مجوز/قرارداد رسمی)
1. **درگاه پرداخت واقعی**: در `PaymentActivity.kt` تابع `startPaymentGateway` را با SDK یا API
   یک PSP مجاز (زرین‌پال، آی‌دی‌پی، به‌پرداخت ملت و ...) جایگزین کنید. نیاز به Merchant ID دارید.
2. **موجودی واقعی کارت سوخت**: باید با API رسمی سامانه هوشمند سوخت (شرکت ملی پخش فرآورده‌های نفتی)
   یکپارچه شوید؛ این API عمومی نیست و نیاز به مجوز رسمی دارد. فایل `StationRepository.kt` را
   می‌توانید به فراخوانی Retrofit به سرور خودتان تغییر دهید.
3. **لیست واقعی جایگاه‌ها و مختصات نقشه**: پیشنهاد می‌شود از Google Maps SDK یا Neshan/Balad
   (نقشه‌های ایرانی) برای نمایش روی نقشه استفاده کنید و داده جایگاه‌ها را از سرور خودتان یا
   API‌های عمومی موجود بگیرید.
4. **احراز هویت کاربر** (ورود با شماره موبایل/کد ملی) برای اتصال به کارت سوخت شخصی هر کاربر.

## نکته امنیتی
هرگز کلید API درگاه پرداخت یا اطلاعات حساس کاربران را مستقیم داخل کد اپلیکیشن (کلاینت) قرار ندهید؛
این کارها باید از طریق سرور بک‌اند شما انجام شود.
